🚀 Getting started

1. Add OpenUtility to Discord. 2. Sign in to the web dashboard with Discord. 3. Select a server you can manage. 4. Configure the systems you need.

OpenUtility works best when its role is high enough to manage the roles it needs to protect or moderate, with View Audit Log enabled for security features.

⚙️ Web Dashboard

Use the server selector to choose a manageable guild, then configure Overview, Server Configuration, Security Center, Moderation, Logging, Welcome and Embed Builder.

🛡️ Security Center

OpenUtility combines Anti-Nuke, threat scoring, burst detection, raid protection, permission escalation monitoring, protected resources, trusted actors, Panic Mode and recovery snapshots.

Keep the bot role above roles it must manage, limit trusted users, protect the bot token and test recovery before relying on it during an incident.

Security protection is not a guarantee against every Discord attack. Use least-privilege permissions and keep Discord security settings reviewed.

🤖 AutoMod 2.0

Configure message-level protections including spam, invites, links, excessive mentions, duplicate content, bad words, caps and @everyone/@here abuse.

👋 Welcome System

Create custom join and leave messages, rich embeds, DMs and automatic roles. Supported variables include {user}, {user.mention}, {server}, {membercount} and {avatar}.

🛡️ Moderation & Cases

Warnings, timeouts, kicks, bans and AutoMod violations can be organized into staff-friendly cases with targets, reasons and moderators.

📋 Advanced Logging

Route member, message, moderation, role, channel, voice and security activity into dedicated channels where supported. Keep security logs restricted to staff.

🎨 Embed Builder

Create Discord embeds with live preview, content, author/style, media, fields, JSON editing and send options. Webhook destinations should be verified before sending.

⚙️ Server Configuration

Manage command behavior, welcome settings, AutoMod, security, logging channels, moderation defaults, trusted users and protected channels or roles from one place.

🧰 Utilities

Password generation, QR generation, server information, user information, reminders and other everyday developer/server tools.

🔐 Permissions

Discord remains the authority for guild permissions. Security features may require View Audit Log; moderation features require the corresponding Discord permissions. Never share the bot token.

🔧 Troubleshooting

Server is missing

Confirm you can manage the server, OpenUtility is invited and refresh the dashboard.

Bot appears offline

Check the OpenUtility status page and bot hosting logs.

Security events are not detected

Check View Audit Log, role position, enabled rules and trusted/protected resource configuration.

Dashboard keeps asking for login

Clear OpenUtility cookies, sign in again and verify OAuth configuration.

Dashboard or API is unavailable

Check the OpenUtility status page.
