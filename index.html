Questions, answered

Before you bring your bot over.

A few details about the HostCraft Discord bot hosting project.

What is Discord bot hosting?

It provides an always-on server environment for your Discord bot, so it can respond to events and commands without depending on your personal computer.

Which languages will be supported?

Node.js and Python are planned starting points. Java and additional runtimes are on the roadmap. Final availability will be confirmed before launch.

Will I be able to deploy from GitHub?

A Git-based deployment workflow is part of the proposed platform experience. Repository connection and automation details will be confirmed as development progresses.

Can I manage my bot token?

The planned control experience includes environment configuration. Never put your Discord bot token in public source code or commit it to a repository.

Are plans available to purchase now?

This website introduces the service direction. Ordering, package specifications and pricing will be enabled after the hosting platform is ready.

Where can I get help?

Use the HostCraft support or sales channel you normally contact for hosting enquiries. Official service links will be added here when they are ready.
