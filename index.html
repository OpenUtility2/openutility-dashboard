Questions, answered

Good to know before you launch.

A few basics about the HostCraft bot hosting experience.

What is Discord bot hosting?

It gives your bot a server environment to run continuously, so it can respond to events and commands without relying on your personal computer.

Which programming languages will be supported?

The planned launch focus is Node.js and Python, with Java and additional runtimes considered for future support. Final availability will be confirmed when the service launches.

Can I deploy my bot from GitHub?

Git-based deployment is part of the proposed feature set. The exact repository connection and automatic deployment workflow will be confirmed before launch.

Will I be able to manage environment variables?

The planned management experience includes secure configuration for bot tokens and other environment variables. Never commit your Discord bot token to a public repository.

Is the service available now?

This is an early website concept. Plans, infrastructure, runtime availability and ordering will need to be connected and verified before accepting customers.
