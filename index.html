Questions, answered

Good to know before launch.

Some quick details about the upcoming HostCraft Discord bot hosting service.

What is Discord bot hosting?

Discord bot hosting provides a server environment where your bot can run continuously, so it can respond to events and commands without depending on your personal computer.

Which programming languages will be supported?

Node.js and Python are among the planned runtime options. Java, Bun and additional environments are being considered. Final availability will be confirmed before launch.

Will I be able to deploy from GitHub?

A Git-based deployment workflow is part of the planned experience. The exact repository connection and automation options will be announced once finalized.

Can I manage my bot token securely?

The planned control panel includes separate environment configuration so sensitive values do not need to be stored in your source code. Never commit a Discord bot token to a public repository.

Is HostCraft bot hosting available now?

This website introduces the upcoming service. Orders, package specifications and launch availability will be announced after the hosting platform is ready.
