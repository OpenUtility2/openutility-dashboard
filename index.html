Need to know

Frequently asked questions.

Will my bot server be created automatically?

That is the intended flow. The website will send an approved order to the HostCraft backend, which will create the server through the Pterodactyl Application API. That backend connection is not active yet.

Where will I manage my bot?

The planned customer panel is panel.hostcraft.xyz. It will provide access to server controls, console, files and resource usage after account and panel integration is complete.

Which runtimes will be available?

The initial configuration offers Node.js, Python and Java as planned runtime choices. Exact versions and egg configurations will be confirmed against the Pterodactyl node setup before launch.

Do I need to share my Discord bot token here?

No. This setup page does not ask for your bot token. Tokens should be added later through a secure environment-variable interface in the authenticated customer panel.

Are the prices final?

Not yet. The resource tiers shown are proposed package specifications. Final prices will be added once infrastructure costs and billing rules are confirmed.
