Helpful answers

Good to know.

Quick answers to common setup questions.

How do I add OpenUtility to my server?

Choose Add to Discord, select the server, review the requested permissions, and authorize the installation. You need the appropriate server permissions to complete this step.

Why can't I see my server in the dashboard?

Confirm that you're signed in to the correct Discord account, that you own the server or have permission to manage it, and that OpenUtility has been installed where required.

Where do I configure moderation and logging?

Open the dashboard, select your server, and use the available Configuration, AutoMod, and Logging sections. Available options can depend on the bot's setup and your access.

Where can I get help or report a problem?

Start with the documentation and service status page. If the problem persists, visit the GitHub issues page or ask in the support Discord.
